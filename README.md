# 阅读生词 v3.0.0

这是原 CET6 Review 项目的极简重构版，只保留一个用途：**保存阅读中遇到的生词/短语**。

## 保留的能力

- 保存单词或短语
- 可附带中文义、来源、原句、备注
- 相同词条再次保存时更新内容并累计遇见次数
- 查看已保存词条
- 删除单条记录
- IndexedDB 本地持久化

## 已删除

固定 CET6 词库、每日复习、认识/忘记、间隔调度、轮次、词典/音标、统计、历史、易错词、备份导入导出、Firebase/Supabase 云同步、相关配置与测试代码全部移除。

## 数据兼容

为了保留旧版已经保存的“阅读生词”，仍使用：

- IndexedDB 数据库：`cet6-review-db`
- 数据库版本：`4`
- 对象仓库：`readingWords`

新代码**只访问 `readingWords`**。旧版复习相关对象仓库即使仍存在于浏览器 IndexedDB 中，也不会再被读取、修改或展示；本版不会主动删除它们，以避免升级时进行破坏性数据库迁移。

直接覆盖部署到原 GitHub Pages 地址即可。不要清除网站数据，否则会同时删除阅读生词。
